# Educineva 教师管理后台 (Educineva Teacher Admin Console)

面向课堂教学场景的**纯教师端控制台**（与学生端视图完全隔离），专为教师配置互动小游戏参数、出题策略、队伍人员调配并向独立游戏大屏幕下发数据。

本系统严格参照 UI 设计稿规范（`设计/1.png` ~ `5.png`），采用 **React + TypeScript + Tailwind CSS** 构建高还原度的粉色现代教育卡片 UI。

---

## 🌟 核心页面与功能实现

### 1. 全局左侧侧边栏 (Sidebar)
* **Educineva Logo**：品牌粉色（`#e60067`）搭配返回按钮与“教师管理后台”副标题。
* **双核心模块导航**：
  * **Games（游戏管理）**：当前默认高亮选中的主页面，配备手柄图标与柔粉底色（`#fde7f0`）。
  * **Question（题目管理）**：试卷与题库管理页面，可随时一键切换。
* **底部 Teacher 教师账号**：展示教师专属卡通头像、教师账号状态及在线绿点。

### 2. 【游戏管理（Games）】主页面
* **分类标签切换与搜索**：
  * `[课中游戏]`（默认高亮选中，品牌粉色胶囊）与 `[课外游戏]` 无缝切换。
  * 游戏名称实时搜索框，带清空快捷操作与空状态友好提示。
* **8 款课堂互动小游戏网格卡片（4列 x 2行布局）**：
  1. 🏎️ **极速赛车**：答题加速超车，团队总里程争冠。
  2. ⭐ **知识闯关**：阶梯登山挑战，争夺金色智慧之星。
  3. 🚩 **拔河挑战**：全队合力作答积蓄拔河力量。
  4. 🚀 **太空冒险**：宇航员深空探索与能量晶体收集。
  5. 🏀 **答题投篮**：课堂三分球争霸与空心入网扣篮。
  6. 🗺️ **宝藏探险**：海岛寻宝藏宝图与解开航海谜题。
  7. 🏃 **欢乐竞速**：百米冲刺田径赛，热血冲线。
  8. 🏰 **城堡守卫**：协同筑起防御阵线抵御入侵。
* **卡片微交互**：卡片悬浮微升、选中时带有高光轮廓边框、右下角「→ 游戏设定」按钮快速呼出配置面板。

### 3. 右侧抽屉设定面板（点击游戏卡片滑出）
* **头部游戏概览**：微缩游戏卡片预览图、游戏名称、所属类型与关闭按钮。
* **信息提示条**：淡紫色（`#f5eeff`）提示 `ⓘ 每个房间独立保存设定与进度`。
* **基本设定**：
  * **房间名称**：自由命名（默认：例如 `极速赛车 · 一年级数学课堂`）。
  * **题目文件**：关联下拉选择本地试卷（如 `一年级数学 Paper 1`、`二年级数学 Paper 2` 等），显示题数与年级科目。
  * **每轮时长**：3 分钟 / 5 分钟 / 8 分钟 / 10 分钟 / 15 分钟。
  * **游戏轮数**：1 轮 / 2 轮 / 3 轮 / 5 轮。
  * **队伍数量**：2 队 / 3 队 / 4 队（支持动态增减）。
  * **每队人数**：2 人 / 4 人 / 6 人 / 8 人 / 10 人。
* **出题规则**：
  * 支持多种抽题策略切换：
    * `每轮随机抽取 5 题，不重复`
    * `每轮随机抽取 10 题，不重复`
    * `按试卷题目顺序逐题出题`
    * `根据答题表现难度自适应`
    * `易错题与重点高频题优先`
* **队伍管理与学生分队调整**：
  * **对抗模式切换**：支持「分队对抗」与「个人竞速」一键切换。
  * **动态队伍增减**：预置蓝队、红队、绿队、黄队，支持点击「+ 增加对战队伍」和「- 移除队伍」。
  * **队伍人物角色设定**：支持每队独立绑定专属出场人物形象（人物 A 护目镜极速少年、人物 B 粉帽活力少女等）。
  * **学生分队实时调整（核心交互）**：
    * **HTML5 原生拖拽**：按住学生名牌即可跨队伍拖动调换（如将红队的“孙琪琪”拖往蓝队）。
    * **一键快速换队**：悬浮名牌点击箭头图标直接穿梭至对方队伍。
    * **候场大厅（未分队学生池）**：支持将新进入房间的学生拖拽编入各队。
* **底部操作栏**：「取消」与粉红主按钮「创建房间」。

### 4. 房间就绪与数据下发弹窗 (Room Launch Modal)
* 点击「创建房间」后弹出华丽就绪卡片：
  * 生成专属课堂房间号（如 `EDU-8926`），带一键复制功能。
  * 汇总选定游戏、绑定试卷、队伍配置与分配学生明细。
  * 提供「立即启动大屏游戏」按钮，模拟数据下发与游戏大屏幕联机启动动画。

## 🚀 启动与体验方式

### 方式 1：开发环境实时预览（推荐）
在项目目录下执行：
```bash
npm run dev
```
打开命令行提示的本地地址（默认 `http://localhost:3000` 或 `http://localhost:5173`）即可体验热重载开发。

### 方式 2：使用 Node.js 极速服务器
```bash
npm start
```
在浏览器访问：
[http://localhost:3000](http://localhost:3000)

### 方式 3：直接双击打开运行（免安装）
项目已完成静态资源编译，直接在文件资源管理器中双击打开：
`dist/index.html`
即可在任意现代浏览器（Chrome、Edge、Safari 等）中完整体验全部功能与交互。

│   ├── index.css             # Tailwind 样式与自定义滑入动画
│   └── main.tsx              # React 挂载入口
